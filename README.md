## 🚀 Featured Project

### LLM Security Audit Framework

An architecture-aware security assessment framework designed to evaluate the security of LLM-integrated applications.

Rather than executing every security check indiscriminately, the framework first analyzes an application's architecture and selects relevant security assessments based on its implementation.

**Key Features**

- Architecture-aware security auditing
- System prompt security analysis
- Input and output validation
- Prompt injection detection
- Tool and function security assessment
- Threat tracking and alerting
- Deployment-aware security recommendations
- Multi-agent reasoning workflow
- Confidence-based finding validation

**Security Domains**

| Domain | Description |
|---|---|
| System Prompt Security | Evaluating system prompt exposure and weaknesses |
| Input Validation | Identifying malicious and adversarial inputs |
| Output Validation | Assessing insecure LLM-generated outputs |
| Tool & Function Security | Evaluating tool access and execution risks |
| Threat Tracking | Monitoring and reporting security threats |

**Technology Stack**

`Python` `FastAPI` `Ollama` `GPT-OSS` `SQLAlchemy` `MySQL`
